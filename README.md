# 🚀 Fogos Launcher

**Minecraft, without the extra complexity.**

Fogos Launcher is a modern, open-source, and highly optimized Minecraft launcher built for players who value their time. Whether you're a casual builder or a hardcore modder, Fogos provides a seamless, lightning-fast, and secure environment to launch your game. We believe that setting up Minecraft shouldn't be a chore — it should be as easy as clicking "Play."

### ✨ Why choose Fogos?

*   **⚡ Lightning-Fast Performance:** Optimized launch times and minimal RAM usage. Get into your world in seconds, not minutes.
*   **🧩 Seamless Mod Support:** Easily manage and install mods, resource packs, and shaders. Switch between Vanilla, Fabric, Forge, and NeoForge instances with a single click.
*   **🔐 100% Open Source & Secure:** Built with transparency in mind. Our code is fully available on GitHub, ensuring there is no hidden telemetry, bloatware, or malware. Just pure Minecraft.
*   **👤 Flexible Account Support:** Log in securely with your premium Microsoft account or use offline mode to play with friends on local networks or supported servers.
*   **🎮 Multiple Instances:** Keep your modpacks and game versions separate. Create unlimited instances with their own settings, mods, and worlds.
*   **🛠️ Automatic Setup:** Forget about manually installing Java or configuring paths. Fogos handles the technical stuff behind the scenes.

### 🛠️ Built for the Community

Fogos Launcher is developed and maintained by the community, for the community. We are constantly working on new features, performance improvements, and UI updates to make your experience as smooth as possible.
